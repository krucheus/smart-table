# Проектная работа "Умная таблица" для отработки навыков в JS

Приложение собирает данные с сервера и выводит их на экран в формате таблицы с продавцами, покупателями и выручкой. 

## Что сделано
- Сгенерирована разметка таблицы
- Добавлена фильтрация, сортировка, поиск по слову
- Пагинация данных

## Запуск проекта

Создайте папку и перейдите в неё:

```shell
cd <name-folder>
```

Клонируйте репозиторий:

```shell
git clone https://github.com/krucheus/smart-table.git
```

В редакторе кода введите команду в терминале:

```shell
npm run dev
```
